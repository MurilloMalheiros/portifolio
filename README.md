# Portfólio — Murillo Alves

Portfólio pessoal de Murillo Alves, desenvolvedor Full Stack e estudante de Engenharia da Computação, com projetos, experiência profissional, formação e conquistas em robótica.

## Tecnologias

- HTML, CSS e JavaScript, sem etapa de build.
- Ícones Lucide, distribuídos localmente com sua licença em `assets/lucide-LICENSE.txt`.
- Fontes DM Sans e Manrope carregadas pelo Google Fonts.

## Executar localmente

Abra `index.html` no navegador ou, com Python instalado, execute na pasta do projeto:

```sh
python -m http.server 8000
```

Acesse <http://localhost:8000>.

## Estrutura

```text
index.html   Conteúdo e estrutura da página
style.css    Layout responsivo e temas claro e escuro
script.js    Navegação, troca de tema e filtros dos projetos
assets/      Foto, currículo, marca e ícones
```

## Recursos

- Layout responsivo para computador e celular.
- Temas claro e escuro com preferência salva no navegador.
- Navegação por seções e filtros de projetos.
- Currículo disponível para download.
- Seção dedicada à robótica e às conquistas em competições.
